# 架构说明（v2.0 实现）

## 类一览

| 类 | 职责 |
|---|---|
| Time | 时长。归一化到 0≤分秒<60，负数抛异常 |
| Date | 日期。校验真实存在，支持 1900 年起 |
| VideoRecord | 一条记录。构造即合法，没有 setter |
| VideoStore | 容器。唯一性、增删改查、统计、文件读写 |
| ConsoleUI | 菜单、输入、输出。不含任何数据规则 |

## 依赖方向

ConsoleUI → VideoStore → VideoRecord → Time / Date

单向。下层完全不知道上层存在。

## 关键约定

- 编号从 1 开始，非法就抛 std::invalid_argument
- 唯一性由 VideoStore 保证；VideoRecord 只回答"我是不是这一条"
- 修改 = 整条替换（VideoStore::modify）
- 文件格式：`合集 部分 序号 时:分:秒 年-月-日 名字`，空格分隔，名字在最后（因此可含空格）
- 文件损坏 → loadFrom 返回 false，容器清空
- 未实现：应学总时长 / 百分比（属于 Collection，v2.2）

## 与初版草案的差异

- `delete` → `remove`（`delete` 是 C++ 关键字，不能做函数名）
- `isExist` → 私有的 `indexOf`（增删改查四个操作共用一份定位逻辑）
- `partTime` / `collectionTime` → `totalTimeOfPart` / `totalTimeOfCollection`
- 应学总时长：初版计划放“计算器管理类”，实际属于 `Collection`
