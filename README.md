# C-TimeCalculator

## 简介

C++学习时长计算系统是一款可以记录自己学习黑马程序员C++课程的程序。本程序可以录入目标视频信息，然后学一个视频就记录一次信息。计划支持学习进度百分比

写这个程序的目的，是为了解决自己学习过程中练手项目不够的问题，同时也给自己的学习留痕，让自己获得一些正反馈。自己之前也想过用Excel来解决这个问题，但是Excel统计一是因为我不太会一些公式，二是当时不太清楚怎么对视频进行分类，因此还是选择直接靠编写该程序来解决。

这个程序适合正在学习黑马程序员的网课视频的同学使用。

## 如何构建

**环境：**  

- CMake： 3.20 及以上，且需要在PATH中有`cmake`，如果提示找不到`cmake`命令，用 Developer PowerShell for VS 打开终端执行；
- 语言标准： C++20；
- 编译器： Visual Studio 2022 及以上，需勾选“使用 C++ 的桌面开发”工作负载。

实际验证过的环境：VS 2026 + CMake 4.3.1

**命令：**

```powershell
#在项目根目录（含 CMakeLists.txt 的那一层）执行
cmake -S . -B build 
cmake --build build --config Debug
```

**结果：**

- 产物路径：`build\Debug\TimeCalculator.exe`；
- 运行：在`build\Debug\`下双击`TimeCalculator.exe`文件；
- 构建失败：

  - 先看有没有 `C` 开头（编译器）和 `LNK` 开头（链接器）后面跟数字的报错
  - 再看是否输出`xxx.vcxproj -> 路径`
  - 最后检查是否生成目标exe文件

## 使用说明

**启动后：**

- 输入数字进行功能选择
- 每一次操作结束后，回到主界面

**各项输入的含义：**

- 视频名称：可以包含空格
- 合集编号 / 部分编号：从屏幕上列出的菜单里选，输错会提示重输
- 视频序号：任意正整数
- 时长：分三次输入 时、分、秒。**分和秒可以超过 59，程序会自动进位**
  （例如 0 时 0 分 3661 秒会存成 01:01:01）
- 日期：分三次输入 年、月、日。年份不早于 1900，月份 1~12，
  日期必须是当月真实存在的一天（2 月 30 日会被拒绝）

**每项操作：**

- 添加记录：依次输入 名称 → 合集编号 → 部分编号 → 序号 → 时/分/秒 → 年/月/日
- 显示记录：列出全部记录，并显示总条数
- 删除 / 查找 / 修改：先输入 合集编号 + 部分编号 + 序号 定位记录
  - 修改时，新编号输成和旧的一样的值，表示“位置不变，只改其他内容”
- 清空：二次确认后删除全部记录（应学总时长不受影响）
- 退出：按 0

**注：**

- 菜单界面输入错误会重新显示菜单重新输入；输入时输入错误会要求重新输入；未查找到则返回菜单
- 数据保存在程序运行目录下的 `videos.txt`，一行一条记录。
- “运行目录”取决于启动方式——从 IDE 里运行时通常是项目根目录，双击 exe 时是 exe 所在目录。
