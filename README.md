# C-TimeCalculator

## 简介

C++学习时长计算系统是一款可以记录自己学习黑马程序员C++课程的程序。本程序可以录入目标视频信息，然后学一个视频就记录一次信息。最后还可以显示学习进度百分比。

写这个程序的目的，是为了解决自己学习过程中练手项目不够的问题，同时也给自己的学习留痕，让自己获得一些正反馈。自己之前也想过用Excel来解决这个问题，但是Excel统计一是因为我不太会一些公式，二是当时不太清楚怎么对视频进行分类，因此还是选择直接靠编写该程序来解决。

这个程序适合正在学习黑马程序员的网课视频的同学使用。

## 如何构建

**环境：**  

- CMake： 3.20 及以上，且需要在PATH中有`cmake`，如果提示找不到`cmake`命令，用 Developer PowerShell for VS 打开终端执行；
- 语言标准： C++20；
- 编译器： Visual Studio 2022 及以上，需勾选“使用 C++ 的桌面开发”工作负载。

实际验证过的环境：VS 2026 + CMake 4.3.1

**命令：**

```powershell
#在项目根目录（含 CMakeLists.txt 的那一层）执行
cmake -S . -B build 
cmake --build build --config Debug
```

**结果：**

- 产物路径：`build\Debug\TimeCalculator.exe`；
- 运行：在`build\Debug\`下双击`TimeCalculator.exe`文件；
- 构建失败：

  - 先看有没有 `C` 开头（编译器）和 `LNK` 开头（链接器）后面跟数字的报错
  - 再看是否输出`xxx.vcxproj -> 路径`
  - 最后检查是否生成目标exe文件

## 使用说明

**启动后：**

- 输入数字进行功能选择
- 每一次操作结束后，回到主界面

**视频信息输入格式：**

- 时长：小时数不限；分和秒限定在0~59以内；按照时分秒顺序输入，每个数据应用空格隔开
- 日期：格式为年.月.日；个位数可以不用补0。如：26.9.27

**每项操作：**

- 添加应学视频记录： 按照格式输入目标学习视频总时长（时分秒）
- 添加已学视频记录： 逐条输入已经学习过的视频记录（部分，序号，时长，学习日期）
- 显示记录： 选中会自行显示相关记录
- 删除，查找，修改： 输入视频所属部分编号+序号后进行相关操作
- 显示百分比： 选中后会自行显示已学占应学的百分比进度
- 清空：选后会提示是否删除，若是，则删除所有数据
- 退出：按0退出
- **注：**
  - 菜单界面输入错误会重新显示菜单重新输入；输入时输入错误会要求重新输入；未查找到则返回菜单
  - 当前版本数据不保留
